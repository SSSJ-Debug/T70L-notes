> 建立：2026-11-01 22:30

## 一、原厂卡片的真实像素规格（实测，不是估的）

从桌面数据库 `item_info.icon` 里直接导出原厂图标 BLOB 反解得到：

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | **220 × 280** | 与 CellLayout 单元格 1:1 |
| 实体卡 | **180 × 240**，左上 **(20,20)** | alpha>128 的范围 |
| 外轮廓 | 196 × 256，从 (12,17) | 含一圈极淡柔光 |
| 外阴影 | **实体外 12px**，alpha 0→15 | 非常淡，几乎只在深色背景上可见 |
| 圆角 | **5** | 很小，接近直角（视觉上因阴影才显得圆） |
| 渐变 | 对角，左上亮 → 右下暗 | 各卡配色不同 |
| 主图形 | 约 **54×48 ~ 64×42**，中心 **(108-109, 81-83)** | 明显偏上，下半部留给桌面画的文字 |

**关键教训**：一开始只按外轮廓 196×256 做，结果卡片比原生大一圈（大 8%），
在屏幕上非常明显。真正要匹配的是**实体 180×240**。

### 屏幕是 1:1 绘制的（实测验证）

取 PNG 里的像素色和屏幕对应位置的像素色逐点比对：

```
文件夹 PNG center (85,56,255) → 屏幕 (90,54,255)
录像机 PNG center (60,59,66)  → 屏幕 (60,59,65)
```

完全一致 → 桌面把 icon BLOB 原样画上去，**没有缩放、没有 alpha 处理**。
所以图片做成什么样，屏幕就是什么样，可以放心按像素做。

（解析里看到的 `b.a(Bitmap)` 那条 0.98 缩放 + alpha 208 的路径，
并没有作用在这批卡片上，别被它误导。）

## 二、音乐卡片（双八分音符）

### 图形参数（`~/re-tools/t70l/wx2/mkcard3.py`）

```
实体卡 180×240 @ (20,20)，圆角 5，外阴影 12px
渐变   左上 (255,146,96) → 右下 (208,62,122)   红橙
音符   双八分音符，左低右高错落
       符头    rx 11.5 / ry 9.2，斜椭圆 ang -0.22
       左符头  (88, 124)    右符头 (130, 113)   ← 右高 11px
       符干    宽 7，竖直；左 72→124，右 62→113
       横梁    厚 10，右端上扬 10px，两端与符干齐平
       整体    67×72，中心 (109,97)
```

造型取自**华为音乐原版图标**（`HwMediaCenter.apk` 内
`res/drawable-xxhdpi-v4/ic_launcher_icon.png`，192×192）：
符干要粗、横梁要厚、符头接近圆——扁平纤细就会显得"骨架化、发傻"。

改图后重新生成：

```bash
cd ~/re-tools/t70l/wx2
python3 mkcard3.py music /tmp/card_music_new.png
```

### 图形位置为什么是"偏上"的

卡片下半部要留给桌面画的标题文字（"音乐"两字由桌面绘制，不在图里）。
所以主图形中心在 y≈81-97，而不是卡片几何中心 140。
**这是对的，不要往上/往下猛调。**

## 三、改桌面卡片数据的正确时序（踩过三次坑）

桌面是 `priv-app` 系统应用，`am force-stop` 会被系统立刻拉起，
而且**拉起时就把旧数据读进内存**。所以顺序必须是：

```bash
# 1) 先改库
adb shell "sqlite3 /data/data/com.xylink.launcher/databases/_setting.db < /data/local/tmp/x.sql; \
           chown 10024.10024 /data/data/com.xylink.launcher/databases/_setting.db; sync"

# 2) 立刻杀干净（多杀几次，防止刚被拉起）
for i in 1 2 3 4; do
  pid=$(adb shell "ps | grep com.xylink.launcher" | awk '{print $2}' | tr -d '\r' | head -1)
  [ -n "$pid" ] && adb shell "kill -9 $pid"; sleep 1
done

# 3) 再启动
adb shell "am start -n com.xylink.launcher/.app.LauncherActivity"
```

**顺序错了（先杀后改、或改完不杀直接 start）→ 屏幕不会变**，
会误以为图有问题，白折腾半天。

### 装 APK 会触发桌面整体重建（重要）

`adb install -r` 任何被桌面引用的包，桌面会重建 `item_info`：

- `_id` 全部变化（376→386 这种）
- 按插入顺序**重排坐标**，自定义卡片会被挤到第一屏第一格
- 天气/时间等组件的 `appWidgetId` 全部重新分配
- 自定义卡片 icon 可能被改写

**所以**：改图标/位置一律走"改库+杀进程"，不要靠重装 APK。
真要装 APK，装完必须重新校对坐标。

正确的第一屏布局（4 列）：

| 卡片 | screen | cellX | cellY | spanX | spanY |
|---|---|---|---|---|---|
| 时间 | 0 | 0 | 0 | 2 | 1 |
| 天气 | 0 | 2 | 0 | 2 | 1 |
| 电话 | 0 | 0 | 1 | 1 | 1 |
| 日程 | 0 | 1 | 1 | 1 | 1 |
| 消息中心 | 0 | 2 | 1 | 1 | 1 |
| 设置 | 0 | 3 | 1 | 1 | 1 |
| 文件夹 | 1 | 0 | 0 | 1 | 1 |
| 录像机 | 1 | 1 | 0 | 1 | 1 |
| 音乐 | 1 | 2 | 0 | 1 | 1 |

## 四、音乐卡本身的实现

| 项 | 值 |
|---|---|
| 应用 | 华为音乐 `com.android.mediacenter` V7.1.44（从用户手机取出，minSdk 14） |
| 启动 Activity | `com.android.mediacenter/.PageActivity` |
| 卡片类型 | 普通卡片 `itemType=2`, `iconType=2`，icon 存 PNG BLOB |
| intent | `intent:#Intent;component=com.android.mediacenter/com.android.mediacenter.PageActivity;launchFlags=0x30000000;end` |
| 位置 | 第二屏第 3 格 `screen=1, cellX=2, cellY=0` |
| 点击 | 实测正常打开 |

### 顺带查到的机制

- 桌面有 `LauncherProvider`（`content://com.xylink.launcher.data/ItemInfo`，exported）
  可以直接 `content query` 读卡片表，调试很方便
- 卡片定义的"源头"在 `vulture.app.home` 的 `nemo_data.db` → `customedfeatures` 表，
  里面原本就有一条 `音乐` → `ch.blinkenlights.android.vanilla`（Vanilla Music，
  设备上没装所以不显示）。但改它**不会**立刻同步到桌面，
  所以实际改动还是直接写 `item_info` 最可靠。

## 五、翻页手势（adb 模拟不出来，用底层触摸事件）

`input swipe` / `input touchscreen swipe` 桌面一律不认。必须 `sendevent`：

设备：`/dev/input/event2`（`ft5x_ts`，单点，无 MT_SLOT）

```bash
# 脚本已存在设备上
adb shell "sh /data/local/tmp/swipe.sh"       # 向左滑 → 第二屏
adb shell "sh /data/local/tmp/swipe_back.sh"  # 向右滑 → 第一屏
```

## 六、可调参数速查（想再改音符时）

在 `mkcard3.py` 的 `draw_music()` 里：

| 想要的效果 | 改哪个 |
|---|---|
| 音符整体变大/小 | `rx, ry` 和两个符头坐标、`st_w`、`beam_h` 一起等比缩放 |
| 左右错落更明显 | 拉大 `h2y` 与 `h1y` 的差（现在差 12px） |
| 横梁更斜 | `yb = 72.0 - 10.0 * f` 里的 10 改大 |
| 横梁更粗 | `beam_h` |
| 整体上移/下移 | 两个符头的 y 与符干顶端同改 |
| 符头更圆 | `ry / rx` 比例往 1 靠（现在 0.8） |

改完必须跑一遍"改库 → 杀 → 启"，然后截图量尺寸确认：

```bash
python3 pngtool.py /tmp/card_music_new.png    # 看实体是否 180×240
```
