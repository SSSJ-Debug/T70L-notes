# 05 · 云台调节 —— 实现逻辑全解

> 产物：`motor.apk`（约 25KB，零第三方依赖）
> 源码：`源码/06-云台调节/src/com/lm/motor/MainActivity.java`（单文件，约 600 行）
> 运行环境：中移 T70L，Android 4.4.4 / API19 / armv7 / 1G RAM / 1280×800
> 控制对象：TC78S600FNG 步进电机驱动（摄像机云台）

---

## 0. 一句话定位

T70L 的摄像机云台是**步进电机**驱动的（不是舵机、不是连续电机）。这个 App 就是它的控制面板——一个方向盘式的 UI，按住上方"上抬"、按住下方"下压"、点中心"停止"，并实时显示电机状态。

---

## 1. 控制原理：直接写 sysfs

云台电机暴露在 Linux sysfs 下，路径固定：

```
/sys/devices/platform/drvtc78s600fng.2/
├── cmd        # 电机命令：stop / up / down / reset / auto
├── step       # 步数（一次移动多少步）
├── pps        # 脉冲频率（速度，单位 Hz）
└── position   # 当前位置（用于限位检测）
```

App 做的全部事情就是**读写这几个文件**，不落盘、不改系统文件、不碰任何守护脚本。这是它简单、稳定、零依赖的根本原因。

---

## 2. 驱动的语义（实测分析）

### 2.1 cmd 命令

| 命令 | 含义 |
|---|---|
| `stop` | 立即停止 |
| `up` | 上抬（云台上仰） |
| `down` | 下压（云台下俯） |
| `reset` | 复位脉冲 |
| `auto` | 自检（200 步 / 3000Hz） |

### 2.2 读取 cmd 的返回格式

`read("cmd")` 返回的不是简单字符串，而是带前缀的：

```
current motor_cmd is stop
current motor_cmd is up
```

所以 `refresh()` 里要截取 `"current motor_cmd is"` 之后的部分。

### 2.3 step / pps 返回格式

```
step: now step :50
pps:  now freq :1000 Hz
```

也要去掉前缀 `"now step :"` / `"now freq :"`。

### 2.4 position 的限位值

| 驱动值 | 界面中文 |
|---|---|
| `Up` | 上端（已到上极限） |
| `Down` | 下端（已到下极限） |
| `Unknown` | 中间 |

这些映射在 `cn()` 方法里集中处理。

## 3. 关键：普通 App 写 sysfs 的权限问题

`/sys/devices/platform/drvtc78s600fng.2/` 默认权限是 root 可写。普通 App（uid 不是 root）直接 `RandomAccessFile` 写会抛 `FileNotFoundException` 或 `AccessDeniedException`。

所以 `write()` 方法做了**双重尝试**：

```java
String write(String name, String val) {
    try {
        // 第一层：直接写（如果 App 有权限，或系统已把 sysfs 放开）
        RandomAccessFile f = new RandomAccessFile(BASE + name, "rw");
        f.write(val.getBytes("UTF-8"));
        f.close();
        return "ok";
    } catch (Throwable t) {
        // 第二层：走 su（如果设备给了 su 权限）
        try {
            Process pr = Runtime.getRuntime().exec(new String[]{
                "su", "-c", "echo " + val + " > " + BASE + name});
            int rc = pr.waitFor();
            return rc == 0 ? "ok(su)" : ("拒绝:" + t.getClass().getSimpleName());
        } catch (Throwable t2) {
            return "拒绝:" + t.getClass().getSimpleName();
        }
    }
}
```

> **注意**：这台设备上 App 通常**没有 su**（`su -c id` 返回 1）。实测云台的 sysfs 节点对 App 是**可写的**（可能驱动侧已放开权限，或设备做了 `chmod`），所以第一层直接写就能成功。第二层 su 是保险兜底。

## 4. 方向盘式 UI（全自绘）

界面是**纯 Canvas 自绘**（`setContentView(new Panel(this))`，无 XML 布局），深色主题。

### 4.1 布局结构

```
┌─────────────────────────────────────────────┐
│ 云台调节                    [复位] [自检]      │  ← 头部 + 右上角描边按钮
│ T70L · 摄像机云台调节                          │
├──────────────┬──────────────────────────────┤
│              │  步数 STEP                     │
│  方向盘       │  [10] [20] [50] [100] [200]   │  ← 步数胶囊
│  (弧形+箭头)  ├──────────────────────────────┤
│              │  速度 Hz                       │
│   上↑         │  [1000][3000][6000][16000]   │  ← 速度胶囊
│  [停止]       ├──────────────────────────────┤
│   下↓         │  状态 STATUS                   │
│              │  电机 | 限位 | 步数 | 速度      │  ← 四字段实时状态
│              │  本次: 上抬 50 步 · 1000Hz     │
│              │  操作日志（最近 2 条）          │
└──────────────┴──────────────────────────────┘
```

### 4.2 方向盘几何

```java
static final float DCX = 316, DCY = 452;   // 圆心
static final float DR = 172;               // 弧线中心半径
static final float DSW = 76;               // 弧线粗细
static final float CR = 84;                // 中心停止圆半径
```

方向盘是**两段弧形**（不是整圆）：
- 上方弧（上抬）：角度 200°~340°
- 下方弧（下压）：角度 20°~160°
- 左右两侧是空的（留白），中心是"停止"圆

### 4.3 命中判定（hitTest）

```java
String hitTest(float x, float y) {
    float dist = 距离(圆心, x, y);
    if (dist <= CR) return "stop";          // 中心圆 → 停止
    if (dist 在弧环带内) {
        double ang = atan2 角度;
        if (ang >= 190 && ang <= 350) return "up";    // 上方弧
        if (ang >= 10 && ang <= 170) return "down";   // 下方弧
    }
    // 否则遍历所有胶囊按钮（步数/速度/复位/自检）
    return null;
}
```

### 4.4 按住连走（核心交互）

这是云台控制最重要的交互：**按住不动就持续走，松手就停**。

```java
final Runnable holdRun = new Runnable() {
    public void run() {
        if (holdAct == null) return;
        write("pps", String.valueOf(pps));
        write("step", String.valueOf(step));
        write("cmd", holdAct);          // up 或 down
        h.postDelayed(this, 160);       // 每 160ms 重复一次
    }
};
```

- `ACTION_DOWN` 命中上/下弧 → 设 `holdAct`、立即 `doAct`、`postDelayed(holdRun, 160)`
- 每 160ms 重复写一次 cmd（保持电机持续运动）
- `ACTION_UP` → 清 `holdAct`、取消 holdRun、写 `cmd=stop`（松手立即停）

### 4.5 实时状态轮询

```java
final Runnable tick = new Runnable() {
    public void run() {
        refresh();                 // 读 cmd/position/step/pps 四个 sysfs 节点
        h.postDelayed(this, 800);  // 每 800ms 刷新一次
    }
};
```

### 4.6 呼吸灯

`breath` 每 60ms 递增 `pulse`，状态卡的运行动态点半径随 `sin(pulse*π)` 变化，让界面看起来是"活的"。

## 5. 一次操作的完整时序（举例：上抬 50 步、1000Hz）

1. 用户先点步数胶囊 `[50]` → `doAct("step:50")` → `step = 50`
2. 用户点速度胶囊 `[1000]` → `doAct("pps:1000")` → `pps = 1000`
3. 用户按住方向盘上方 → `hitTest` 返回 `"up"`
4. `doAct("up")` 依次写三个节点：
   ```
   write("pps", "1000")
   write("step", "50")
   write("cmd", "up")
   ```
5. `holdRun` 每 160ms 重复写 `cmd=up`（保持运动）
6. 用户松手 → `write("cmd", "stop")` → 电机停

## 7. 关键点备忘

1. **电机是步进的**：`step`（步数）+ `pps`（脉冲频率）决定"走多远、走多快"。不是给一个持续命令就一直走——所以"按住连走"要每 160ms 重写一次 cmd。
2. **松手必须 stop**：否则电机会按惯性/最后命令继续走，撞到限位。
3. **写 sysfs 是运行时参数**：不落盘、不改系统文件，重启后云台回到默认状态，App 不会留下任何持久化副作用。
4. **限位是驱动自带的**：`position` 会返回 `Up`/`Down` 表示到顶/到底，App 只管显示，不管停止（驱动自己会停）。
5. **行程约 2800 步**：从一端到另一端全程约 2800 步（两端有限位）。

图标是"深蓝黑卡片 + 竖直滑轨 + 白色滑块 + 上下箭头"，和 App 的方向盘 UI 是同一套语义（调的是俯仰位置）。
