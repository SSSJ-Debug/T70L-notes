# T70L 命令速查

## 0. 环境变量（每次开新终端先跑）

```bash
export PATH=$HOME/re-tools/platform-tools:$PATH
adb connect 192.168.1.153:5555
```

---

## 1. 基础状态

```bash
adb devices -l                  # 设备列表
adb shell id                    # 应该是 uid=0(root)
adb shell getprop ro.build.version.release
adb shell getprop service.adb.tcp.port
adb shell cat /proc/uptime      # 判断是否刚重启过
```

**找设备 IP**（换了网络/重启后 IP 可能变）：
```bash
for i in $(seq 1 254); do nc -z -G 1 192.168.1.$i 5555 2>/dev/null && echo "192.168.1.$i"; done
```

---

## 2. root 相关

```bash
adb root                        # 保险起见执行一次（当前已默认 root）
adb shell su -c id              # 走自带 setuid su，返回 uid=0(root)
adb shell whoami
```

**注意**：`su -c "cmd1; cmd2"` 在这台机器上会被拆错，**一次只传一条**：
```bash
adb shell 'su -c id'
adb shell 'su -c "ls /data"'    # 引号嵌套要小心
```

---

## 3. 文件传输

```bash
adb push local.txt /data/local/tmp/
adb pull /system/build.prop ./

# 传系统分区（需要 remount）
adb shell 'mount -o rw,remount /system'
adb push newfile /data/local/tmp/x
adb shell 'cp -f /data/local/tmp/x /system/xxx
           chown 0:0 /system/xxx
           chmod 644 /system/xxx
           chcon u:object_r:system_file:s0 /system/xxx
           sync'
```

`chcon` 必须做，否则 SELinux 会让文件"存在但读不到"。

---

## 4. 装应用

```bash
adb install -r app.apk                        # 普通安装
adb install -r -d app.apk                     # 允许降级
adb shell pm install -r /data/local/tmp/x.apk # 设备端安装
adb shell pm list packages                    # 列出所有包
adb shell pm list packages -3                 # 只看第三方
adb shell pm uninstall -k --user 0 com.xxx    # 卸载（保留数据）
adb shell pm disable com.xxx                  # 禁用系统应用
```

**分区 `/system` 只读 786MB，装大 App 装到 /data。**

## 5. 启动应用

```bash
adb shell am start -n com.xxx/.MainActivity
adb shell monkey -p com.xxx -c android.intent.category.LAUNCHER 1
adb shell am force-stop com.xxx
```

## 11. 掉链子时的排查顺序

> ⚠️ **先记住：adbd 不一定在 5555。** 原厂看门狗 `enablenetadb` 的默认端口是 **5656**，
> 而且会把端口持久化到 `persist.sys.adbport`。5555 连不上时**第一件事是试 5656**，
> 别急着判断"adbd 死了"。2026-11-01 那次就是靠这个救回来的。

```bash
# 0. 两个端口都试
adb connect <IP>:5555 ; adb connect <IP>:5656
# 还不行就全端口扫一遍（1-20000 足够）
```

```bash
# 1. 端口通不通
nc -z -v -G 3 <IP> 5555
nc -z -v -G 3 <IP> 5656

# 2. adb 服务器状态
adb kill-server; adb start-server; adb devices

# 3. 设备端 adbd 是否在跑（需要已有 root 通道）
adb shell getprop init.svc.adbd      # 应该是 running
adb shell getprop service.adb.tcp.port  # 应该是 5555

# 4. 持久化文件是否还在
adb shell 'grep adb /system/build.prop'
adb shell 'cat /system/etc/install-recovery.sh'
```
