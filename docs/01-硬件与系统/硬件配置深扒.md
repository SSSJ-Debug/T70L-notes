## 1. 主芯片（SoC）

| 项目 | 值 | 依据 |
|---|---|---|
| 芯片 | **Allwinner A83T**（sun8i 家族） | dmesg `lock super standby for a83!`、`Machine: sun8i` |
| 架构 | **8 × Cortex-A7**（ARMv7-A，32 位） | `[mcpm_smp_init_cpus] ncores=8`、CPU part `0xc07` |
| **实际启用** | **只有 4 核** | 见下方“重要发现” |
| 最高频率 | **1.8GHz** | `/sys/.../cpuinfo_max_freq = 1800000` |
| 当前运行 | **3 核在线**（0-2），当前频率 1.8GHz | `/sys/devices/system/cpu/online = 0-2` |
| BogoMIPS | 4800 × 4 = 19200 | dmesg `SMP: Total of 4 processors activated` |
| GPU | **PowerVR SGX544** @ **432MHz** | dmesg `script config pll_gpu to 432 Mhz`，系统有 `pvrsrvctl` 服务 |
| 制程 | 28nm | A83T 规格 |
| 协处理器 | ARISC（AVR 核，v1.70） | dmesg `[ARISC] sunxi-arisc driver v1.70` |

### ⚠️ 重要发现：这颗芯片是 8 核，但只跑了 4 核

内核日志里明确记录：
```
CPU4: failed to boot: -22
CPU5: failed to boot: -22
CPU6: failed to boot: -22
CPU7: failed to boot: -22
Brought up 4 CPUs
SMP: Total of 4 processors activated (19200.00 BogoMIPS)
```
- A83T 物理上是 8 核（2 个 cluster × 4 核）
- 第二个 cluster（CPU4-7）上电失败，返回 `-22 (EINVAL)`
- **这是厂商固件配置的问题，不是硬件坏了**——很可能是 cluster1 的电源域/CPU 供电没在 sys_config 里开
- **理论上可以解锁到 8 核**，需要改 u-boot 的 `cluster1` 电源参数，风险中等（刷错会不开机，但有 fastboot/recovery 兜底）

> 现状：4 核 A7 @1.8GHz，日常播放音乐/视频完全够用，跑分接近骁龙 410。

## 2. 内存

| 项目 | 值 |
|---|---|
| **总容量** | **1024MB（1GB）** |
| 类型 | DDR3（A83T 平台标配），双通道 |
| 内核可用 | 729500 KB（≈712MB） |
| 内核保留 | 319076 KB（≈311MB，给 ION/CMA/GPU/显存） |
| 高端内存区 | HighMem 396MB |
| **交换分区** | **256MB zram**（压缩内存，不是真实 swap） |
| 实际可用（Android 层） | 1002MB（`totalMem`），当前剩余 597MB |

### 内存都花在哪了（311MB 保留区）
内核启动参数里写死了：
```
ion_cma_list=120m,288m,512m    # 给摄像头/显示/视频解码的连续内存池
vmalloc=384M
```
- `ion_cma_list=120m,288m,512m` → ION 从 120MB 起分配，最大可到 512MB
- 这是为了 **视频会议** 场景预留的（多路 1080p 编解码）
- **如果改造成音箱，这 311MB 基本浪费了**，可以调小 `ion_cma_list` 多释放一些内存

## 3. 存储

| 项目 | 值 |
|---|---|
| **颗粒** | **SanDisk DG4008**（eMMC 4.5） |
| 厂商 ID | `0x45`（SanDisk） |
| OEM ID | `0x0100` |
| 序列号 | `0xc5594707` |
| **标称容量** | **8GB**（原始 15273600 扇区 = 7.28GiB） |
| 接口 | eMMC，8bit，UHS-DDR50 @ 50MHz |

### 分区表（真实布局）
```
mmcblk0      7.28 GiB   总容量
├─ p1  UDISK      5.62 GiB  → /data（用户数据 + 内置存储）
├─ p2  bootloader 8.00 MiB  （u-boot + sys_config）
├─ p3            1 块      （占位）
├─ p5  env        8.00 MiB  （启动环境变量）
├─ p6  boot       8.00 MiB  （内核 + ramdisk）
├─ p7  system     384 MiB   （系统，只读）
├─ p8  misc       8.00 MiB
├─ p9  recovery   16.00 MiB
├─ p10 cache      384 MiB
├─ p11 metadata   8.00 MiB
├─ p12 private    8.00 MiB  （vfat，厂商密钥区）
├─ mmcblk0boot0   4.00 MiB
└─ mmcblk0boot1   4.00 MiB
```

**实际可用空间**
- `/data`：5.67GB，当前剩余 **5.2GB**
- `/system`：384MB（**注意：比一般机器小，装不下几个系统应用**）
- `/cache`：384MB

> 提示：`system` 分区只有 384MB，塞 Magisk/大模块会爆。装 App 一律装到 `/data`。

## 4. 屏幕

| 项目 | 值 | 依据 |
|---|---|---|
| **物理分辨率** | **800 × 1280**（竖屏面板，横屏使用） | `fb0 virtual_size = 800,2560`（双缓冲） |
| **逻辑分辨率** | **1280 × 752**（扣掉 48px 状态栏） | Android `widthPixels/heightPixels` |
| 刷新率 | **59.0 ~ 59.1Hz** | `disp info: fps:59.1` |
| 色深 | **24bpp（RGB888，1677 万色）** | `fb0 bits_per_pixel = 24` |
| 密度 | **160dpi**（系统按 1.0 缩放） | `densityDpi = 160` |
| 面板接口 | **LCD（MIPI/RGB）** | `disp info: lcd output` |
| 背光 | PWM 调光，当前亮度 178/255 | `backlight(178)` |
| 估算尺寸 | **约 8 英寸**（1280×800，16:10） | 见下方说明 |
| 屏幕 ID | `lcd_screen_id=0`，`board_id=4` | 内核 cmdline |

### 关于尺寸的说明
系统上报的 `xdpi=282.713 / ydpi=110.434` 是**厂商乱填的**（横竖两个方向差了 2.5 倍，物理上不可能）。
按 1280×800 + 常见规格反推：
- 16:10 比例，8 英寸 → 172×107mm
- 10.1 英寸 → 217×136mm

**实际是 8 英寸级别**（和会议终端常见的 8 寸屏一致）。
你拿尺子量一下屏幕对角线就能确认。

### 面板型号
厂商**没有**把面板型号写进系统（没有 `/sys/class/lcd` 节点，u-boot 里也只有驱动名占位）。
**结论：查不到具体面板厂（BOE/天马/京东方等）**，这是白牌模组的常见做法。
能确定的是：8 寸、1280×800、MIPI 接口、PWM 背光、59Hz。

## 7. 音频（改音箱的关键）

| 项目 | 值 |
|---|---|
| **Codec 芯片** | **Allwinner AC100** |
| 声卡 | `0 [snddaudio]` |
| 主通道 | `SUNXI-I2S0 / ac100-aif1`（playback 1 + capture 1） |
| 语音通道 | `Voice / ac100-aif2` |
| 蓝牙音频 | `bt-dai / ac100-aif3` |
| PCM 设备 | 5 组（`/dev/snd/pcmC0D0p` ~ `pcmC0D4p`） |
| 录音/放音 | 均支持（capture + playback 成对） |
| 功放 | 外部 I2S DAC + 功放（AC100 输出 I2S，经外部芯片放大） |

**实测结果**：媒体音量 15/15，Vanilla Music 播放时正确获取音频焦点（`stream: 3` = STREAM_MUSIC，`gain: GAIN`），链路通畅。

> 改音箱注意：多路 PCM 说明支持**同时多路音频**（会议场景需要），做提示音+音乐混播时有用。

## 12. 一句话总结这台机器

> **2019 年的 8 英寸会议终端**：全志 A83T（8 核只开 4 核）+ 1GB 内存 + 8GB SanDisk eMMC + 1280×800 屏。
> 硬件规格 ≈ 2014 年中端平板，但**接口齐全**（千兆网口、4G、USB、DC 供电、串口、摄像头、麦克风阵列）。
>
> 做智能音箱：**完全够用**。瓶颈是 1GB 内存和 2.4G 单频 WiFi，不是 CPU。
